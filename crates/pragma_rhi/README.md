# pragma_rhi

Part of [pragma.component-rhi](https://github.com/razedproduction/pragma.component-rhi): a Render
Hardware Interface for game engines and frameworks built on
[pragma.core](https://github.com/razedproduction/pragma.core).

Early development (M4): instance, adapters, devices, buffers, textures, views, samplers,
shader modules, bind groups, render and compute pipelines, command recording on the
pragma.core frame graph, submission; surfaces and the swapchain, frames in flight, deferred
destruction, a staging belt for uploads and asynchronous readback.
